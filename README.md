# Calculadora JSX

Calculadora construida con React y JSX, con soporte de teclado y operaciones básicas.

## Características

- Suma, resta, multiplicación y división
- Porcentaje y cambio de signo
- Historial de la operación en curso sobre la pantalla
- Control desde el teclado físico (números, `+ - * /`, `Enter`, `Backspace`, `Escape`)
- Diseño tipo pantalla LCD retro

## Requisitos

- Node.js 18 o superior

## Instalación

```bash
npm install
```

## Uso

Modo desarrollo (con recarga en caliente):

```bash
npm run dev
```

Compilar para producción:

```bash
npm run build
```

Previsualizar la build de producción:

```bash
npm run preview
```
